## Streamlit Secrets

Secrets находятся в Streamlit Cloud:

`App → Manage app → Settings → Secrets`

Основные параметры:

| Параметр | Назначение |
|---|---|
| `SUPABASE_URL` | Адрес проекта Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | Серверный доступ приложения к закрытым таблицам Supabase |
| `ADMIN_USERNAME` | Начальный логин администратора |
| `ADMIN_PASSWORD_HASH` | Хеш начального пароля, не сам пароль |
| `TELEGRAM_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | Чат для результатов, ошибок и восстановления доступа |
| `GEMINI_API_KEY` | Доступ к Gemini |
| `GROQ_API_KEY` | Доступ к резервному ИИ Groq |

CRM-токены и рабочие настройки amoCRM после подключения хранятся через защищённую админку и Supabase.

## Supabase

В Supabase используются:

- SQL Editor для применения миграций из папки `db`;
- Database для настроек и пользователей;
- Storage для управляемых файлов;
- закрытый `service role/secret key` для серверного доступа.

Миграции выполняются по порядку:

1. `db/001_crm_admin.sql`
2. `db/002_admin_assets.sql`
3. `db/003_admin_users.sql`
4. `db/004_admin_password_recovery.sql`

`SUPABASE_SERVICE_ROLE_KEY` нельзя размещать в коде, документах, скриншотах или браузерном JavaScript.

## Что где проверять

### Сайт не открывается

1. Открыть Streamlit Cloud.
2. Проверить состояние приложения и логи.
3. Убедиться, что выбран репозиторий, ветка `main` и файл `audit_app.py`.
4. При необходимости нажать Reboot.

### Изменения не появились

1. Проверить последний коммит в нужном репозитории GitHub.
2. Проверить версию внизу приложения.
3. Проверить логи деплоя Streamlit.
4. Убедиться, что проверяется нужный контур: Test, Khalil или BTG.

### Не приходит Telegram

1. Проверить `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID` в Streamlit Secrets.
2. Убедиться, что бот добавлен в нужный чат.
3. Проверить, что бот может отправлять сообщения.
4. Посмотреть диагностику в логах Streamlit.

### Не работает ИИ

1. Проверить наличие `GEMINI_API_KEY` и `GROQ_API_KEY`.
2. Проверить квоты Gemini.
3. Проверить лимиты Groq.
4. Посмотреть внутреннюю диагностику, отправленную в Telegram.

### Не работает админка

1. Открыть адрес с `?admin=1`.
2. Проверить подключение Supabase.
3. Проверить, что все SQL-миграции выполнены.
4. При забытом пароле запросить одноразовый код в Telegram.

### Не работает CRM

1. В админке проверить выбранного CRM-провайдера.
2. Проверить домен amoCRM, воронку, этап и ответственного.
3. Запустить проверку подключения.
4. Активировать CRM только после успешной проверки.

## Правила безопасности

- Не отправлять токены, API-ключи и пароли в чатах и по email.
- Не добавлять `.streamlit/secrets.toml` в GitHub.
- Не показывать `SUPABASE_SERVICE_ROLE_KEY` на скриншотах.
- Для SMTP, Google и других сервисов использовать пароли приложений, если они понадобятся.
- При утечке ключа сразу отозвать его и выпустить новый.
- Перед изменениями в продакшене обязательно проверять Test.
